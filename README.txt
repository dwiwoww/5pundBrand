SPUNBRAND WEBSITE
=================

File:
- index.html  : struktur dan konten website
- style.css   : desain, layout, dan responsive styling
- script.js   : menu mobile, filter kategori, dan tombol pesan WhatsApp
- assets/goodiebag-sample.jpeg : foto contoh produk yang Anda unggah

Cara menjalankan:
1. Ekstrak folder/ZIP.
2. Pastikan index.html, style.css, script.js, dan folder assets berada dalam satu folder sesuai susunan.
3. Buka index.html menggunakan browser.

Catatan:
- Harga Rp3.000, Rp4.000, dan Rp5.000 ditampilkan sebagai harga indikatif/mulai dari.
- Harga akhir perlu dikonfirmasi berdasarkan ukuran, bahan, jumlah, dan detail sablon.
- Link WhatsApp, email, Instagram, dan Shopee sudah dipasang.
- Font Google membutuhkan koneksi internet; website tetap menggunakan fallback font jika offline.
